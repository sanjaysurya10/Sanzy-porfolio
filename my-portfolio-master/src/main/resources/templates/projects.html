AI Chat-Bot

This project involved the development of an intelligent chatbot capable of understanding and responding to user queries using Natural Language Processing (NLP) and voice-based interaction. Built using Python, the system integrates speech recognition and text-to-speech modules to enable seamless two-way communication. The chatbot can handle general conversation, answer factual questions, perform tasks like opening applications or fetching data from the internet, and provide real-time voice responses.

E-mail Authentication

Built a full-stack Email Authentication System using Spring Boot, Spring Security, and ReactJS. The application includes secure login with email-based OTP verification and JWT (JSON Web Token) for session handling. JavaMail is used to send OTPs to users during authentication. The frontend, developed with ReactJS and styled using Bootstrap 5, provides a responsive and user-friendly interface. MySQL is used for storing user credentials and verification data securely, ensuring a robust and scalable authentication workflow.

Employee Management System

Developed an Employee Management System using Java, MySQL, and Java Swing. This desktop application enables users to perform CRUD operations on employee records, including adding, updating, deleting, and viewing details. Java Swing provides a user-friendly GUI, while MySQL ensures secure and efficient data storage. The system demonstrates effective integration of frontend and backend technologies for managing organizational data.
